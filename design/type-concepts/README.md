# Free Market Wildlife lettering concepts

Preview-only studies generated with the built-in imagegen tool. Pixel Slab was selected and is now implemented as original local bitmap fonts on the homepage. All prompts request black-and-white pixel lettering. The glyph-grid sizes describe design targets; generated studies are not final measured bitmap fonts.

## Classic Block

File: `01-classic-block.png`

### Prompt

```text
Use case: logo-brand. Create one typography concept sheet, wide landscape composition, PURE BLACK background and PURE WHITE pixel lettering, no gray or other colors. Subject: improve the title lettering for the existing Free Market Wildlife website. EXACT text on exactly two left-aligned lines: first line "FREE MARKET", second line "WILDLIFE". Concept: CLASSIC BLOCK. Beautiful original bitmap typography, clean confident squared uppercase letters, deliberate consistent stroke weights, balanced optical spacing, sturdy proportions, simple readable classic game-title sensibility without any nostalgic console branding. A carefully designed 12x16 logical grid per letter, solid pixel shapes, strictly axis-aligned edges with occasional precise stepped corners, all visible elementary pixel squares equal. Words should feel bespoke, mature, and understated. Large black margins, only the two lines of white text. No illustrations, no icons, no logo emblem, no subtitle, no website mockup, no frame, no effects, no perspective, no glows, no shadow, no bevel, no broken/glitch pixels, no antialiasing or smooth curves. Typography study only, flat crisp binary pixel art. Both lines share the same cap height and align left. Do not stretch WILDLIFE to match the longer line; preserve natural character widths.
```

## Pixel Slab

File: `02-pixel-slab.png`

### Prompt

```text
Use case: logo-brand. Create one excellent original pixel-type wordmark study. Landscape image, pure black background, pure white letters, only black and white no grayscale. EXACT two-line text: "FREE MARKET" on the first line and "WILDLIFE" on the second. Left aligned, identical cap heights on both lines, natural word widths. Concept: PIXEL SLAB. Elegant compact pixel-art slab-serif lettering with a little character, similar in spirit to carefully hand-drawn independent magazine mastheads translated into an authentic bitmap grid. Short square serifs, strong upright stems, spacious counters, consistent stroke weight, meticulous kerning, restrained tiny single-pixel corner cuts. Design on a logical roughly 16x20 grid per glyph so fine 1-pixel serif details are possible, all elementary pixels equal-sized, no vector smoothing. Premium authored typography that balances human warmth and strong readability. Keep it simple, not ornate. Only the two text lines at large scale with generous black margin. No logo symbol, scenery, illustrations, labels, explanatory text, subtitle, frames or panels. No gray, gradients, light bloom, outlines, 3D, bevels, shadows, texture, glitching, distressed lettering, smooth antialiased curves, or faux scanlines. An actual two-color crisp pixel lettering concept, square pixel edges clearly visible.
```

## Soft Pixel

File: `03-soft-pixel.png`

### Prompt

```text
Use case: logo-brand. Generate one original two-line pixel-lettering concept for Free Market Wildlife. Landscape typography study, pure BLACK #000000 background, pure WHITE #ffffff letters, no other color or grayscale. EXACT text, first line "FREE MARKET", second line "WILDLIFE". Concept: SOFT PIXEL. Wide, inviting, carefully drawn uppercase bitmap lettering. Strong simple forms with open counters and subtly rounded corners made entirely from deliberate square-pixel stair steps. Slightly friendlier than conventional block typography, with custom attractive W, M, R, and E shapes, even visual weight, careful spacing, sophisticated indie creative identity. Use a consistent roughly 14x18 logical grid per glyph; all elementary pixels are identical square size. Pixel rounding must be visibly stepped and not blurred or anti-aliased. Both lines left aligned, equal cap heights, natural width so WILDLIFE is shorter, generous black negative space. Typography only; no icons, emblem, tagline, illustrations, scenery, browser, captions, concept names, or frame. No smoothing, no gray, no cyan, no glow, no drop shadow, no extruded depth, no gradients, no distortion, no damaged or glitch pixels. Clean, calm, high-quality authored bitmap wordmark.
```
